📢 使用提示

本项目目前处于实验推广阶段，服务器性能有限：多人同时提问时会自动排队，回答速度会明显变慢。请耐心等待，不要重复点击发送。

如果大模型回答不好，欢迎点 👎 并填写原因（例如“希望补充审核/分发步骤”），我们会据此补充资料、修复问题。

加内容、觉得系统有改进的地方，或者你的需求，可以点下面的「💬 反馈 / 提需求」填写，也可以随时在右上角「⚙ 更多 → 💬 反馈」里提交。

使用文档

新人AI导师有两个独立入口： 知识库问答用于了解项目、查资料； 模拟答辩用于按关键词/PPT 练习，AI 导师提问并评价。 两个入口的权限由管理员分开开通，未开通的会置灰。

详细操作和管理员功能见「完整手册」标签。

一、登录与入口

  1. 用公司邮箱注册 / 登录；忘记密码找管理员重置。
  2. 登录后选择入口：📚 知识库 或 🎓 模拟答辩；未开通的入口会置灰。

二、知识库：选库提问

  1. 左侧选择一个知识库。没有权限的库也会显示，但会置灰并标「🔒 未授权」； 点它只会提示联系管理员开通，不会进入。
  2. 输入框输入问题，Enter 发送，Shift+Enter 换行。
  3. 图片提问：截图直接 Ctrl+V 粘贴，或把图片拖进输入框， 会随问题一起提交；一次可以贴多张。
  4. 回答下方有引用，点角标定位原文；点文件名可预览。
  5. 输入栏可切换「💬 上下文」「📏 回答详略」「🧠 深度思考」。

三、深度思考

默认关闭，回答更快。复杂问题可点「🧠 深度思考」打开：页面会先展示模型思考过程， 答案出来后仍可在答案上方折叠查看。

四、模拟答辩（新人AI导师）

  1. 右上角「🎓 模拟答辩」进入，会在新标签页打开，不用重新登录。
  2. 两种方式：上传 PPT 演练，或 关键词直练（不用 PPT）。
  3. 选择题数、出题难度和出题依据的知识库，AI 导师逐题提问并评价。
  4. 练习模式可随时看参考答案和依据；答辩模式答完统一看解析。

五、补充内容与反馈

  • 「✍️ 写内容」记录经验，支持 Ctrl+V 粘贴截图。
  • 「添加」上传文件/文件夹/zip；支持 PDF、Word、PPT、Excel、DBF、SQL、 文本、图片等，zip 会自动解压。
  • 「⚙ 更多 → 💬 反馈 / 提需求」提交资料补充、改进建议、新需求； 觉得回答有用可以点 👍，会作为测试素材。
  • 「⚙ 更多 → 📖 使用文档 → 完整手册」查看详细说明。

六、常见问题

  • 排队/变慢：多人同时提问会自动排队，页面会显示等待秒数，请勿重复发送； 急用可申请自己的大模型 Key。
  • 知识库没答上：先确认选对库；仍没有就点「反馈」补充资料。
  • 权限：看不到或置灰的库，找管理员在「用户管理」里开通/分配。

项目定位

「新人AI导师」面向新入职、转岗和接手项目的同事，目标是把“翻文档、找人问、没人陪练” 变成可随时使用的项目导师。系统分为两个独立但互补的模块：

  • 知识库问答：帮助新人了解项目情况，助力快速上手。
  • 模拟答辩：基于学习的关键字，AI 模拟导师提问并评价； 帮助新人自检学习效果，助力查漏补缺，释放导师精力。

解决的痛点

  • 资料分散：需求、方案、接口、部署手册、周报、遗留问题散落各处，逐篇翻阅耗时。
  • 上手周期长：新人对项目没有全局认识，不知道从哪问、问谁。
  • 导师时间被占：同一个问题反复回答，缺少标准化的练习和反馈。
  • 经验留不下来：口头经验、临时结论、环境信息没有沉淀。
  • 权限与安全：项目资料需要按人/按库隔离，数据不出内网。

现在具备的能力（2026-11）

  • 知识库问答：按项目建库、上传文件/文件夹/zip、后台建索引、混合检索 + 重排 + 大模型回答、引用定位、原文预览。
  • 图片提问：截图 Ctrl+V 粘贴或拖进输入框，随问题一起提交；不再需要点图片按钮。
  • 深度思考：可开/关；开启时展示模型思考过程，关闭时回答更快。
  • 模拟答辩：上传 PPT 或关键词直练；基础/标准/挑战难度；练习/答辩模式；逐题评价和报告。
  • 权限可见：没有权限的知识库也会显示但置灰，点击提示找管理员开通；管理员可分别分配问答/答辩权限。
  • 反馈与改进：更多菜单可提交资料补充、改进建议、新需求；点赞的问答会整理为测试素材。
  • 使用文档：内置快速上手和完整手册；首次进入有引导；进入提示文案可由管理员修改。

技术架构简览（非技术同事可跳过）

文件夹 / 上传目录 → 解析抽文本 → 分块 → 每库独立索引（chunks.jsonl）+ 语义向量（vectors.npy）
提问 → 问题理解/拆解 → BM25 + 向量混合召回 → 融合去重 → 重排精排 → 组装提示词 → 大模型流式生成 → 界面展示 + 引用来源 + 图片缩略图

部署在公司内网；知识库和问答数据按权限隔离； 支持个人大模型 Key，避免多人挤公共 Key 排队。
