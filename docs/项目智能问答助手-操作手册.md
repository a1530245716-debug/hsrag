> 适用对象：应届生、新入职同事、实习生
> 文档版本：v2.0（2026-11-09）
> 系统地址：https://rag.example.com/
> 说明：本文截图使用「应届生演示」账号和演示知识库，不代表真实客户资料

## 一、这个系统能帮你做什么

刚进项目时，最常见的问题是：

- 业务手册、培训 PPT、部署文档散落在各个文件夹，不知道从哪看起；
- 遇到一个名词、一个流程，翻半天文档还找不到；
- 想练习答辩，但没有人扮演评委连续提问；
- 学到的经验只留在自己脑子里，下次又忘了。

「项目智能问答助手」把项目资料建成知识库，你用中文直接提问，它从文档里找依据、组织答案，并告诉你**答案出自哪份文档的哪一段**。新人可以把它当成随身的项目导师。

核心用法只有三步：**注册登录 → 选知识库 → 直接提问**。

**典型场景：新项目交接。** 刚接手一个项目时，把交接材料、培训文档、环境信息记录、当前进度/周报、遗留问题等按项目建成一个知识库。之后直接问「这个项目现在做到哪一步」「测试环境和生产环境分别是什么」「某块业务怎么处理」，系统会从资料里找答案并标出处。

和公司 U+ 知识库的关系：U+ 是公司级的 RAG 知识库；本系统更适合做「项目级」的补充——按单个项目自己建库，环境信息、项目进度、会议纪要、个人整理的经验都可以放。两者配合使用，效果更好。

## 二、注册账号

### 2.1 打开系统

按你所在的网络选择地址，优先用内网/VPN，速度会快很多：

| 场景 | 地址 | 说明 |
|---|---|---|
| 办公室/同一局域网 | `http://192.0.2.200:8000` | 最快；IP 可能随 Wi-Fi 变化 |
| 公司 VPN | `http://192.0.2.164:8000` | 连上公司 VPN 后使用，已确认可访问 |
| 外网/手机流量 | `https://rag.example.com/` | 任何地方都能用，但速度较慢 |
| 装了 Tailscale（可选） | `http://100.64.0.10:8000` | 需加入同一 tailnet，不是必需 |

> 内网/VPN 地址以部署机实际地址为准；如果打不开，先用公网地址。手机浏览器也可以直接打开，页面会自动适配。

### 2.2 注册

在登录页点「**注册新账号**」。

> **图：注册页**（截图已从公开仓库移除；本地启动后可在浏览器查看对应界面。）

填写：

| 项目 | 要求 |
|---|---|
| 公司邮箱 | 必须使用公司邮箱（默认只允许 `@examplecorp.com`），**邮箱就是你的登录账号** |
| 密码 | 至少 6 位 |
| 邮箱验证码 | 当前未开启邮件验证时不会出现；如果管理员开启了 SMTP，会多出「获取验证码」一栏，按提示填写 |

说明：

- 不要用 QQ 邮箱、163 邮箱等个人邮箱，系统会拒绝。
- 注册成功后会自动登录，不需要再登录一次。
- 如果提示「只允许 @examplecorp.com 的邮箱注册」，说明你填错了邮箱域名；如果公司邮箱也注册不了，找导师或管理员确认域名白名单。

### 2.3 登录

> **图：登录页**（截图已从公开仓库移除；本地启动后可在浏览器查看对应界面。）

账号填**公司邮箱**，密码是注册时设置的密码。

- 每个账号只能看到自己的知识库，以及别人**只读分享**给你的知识库。
- 登录状态保存在当前浏览器标签页里；换浏览器或清除缓存后需要重新登录。

### 2.4 入口权限与默认知识库

登录后会出现两个入口：**📚 知识库** 和 **🎓 模拟答辩**。

- 入口默认是**置灰**的，需要管理员在「用户管理」里开通；
- 开通「知识库」后，可以进入主界面提问、看引用；
- 开通「模拟答辩」后，可以进入答辩演练；系统会自动把你加入「业务手册（O32/资管培训）」的只读共享，答辩出题和依据默认用它；
- 没开通的入口点了没有反应，联系管理员即可。

知识库权限开通后，默认能看到「业务手册（O32/资管培训）」；其他项目知识库需要管理员额外分享。只读意味着能提问、看引用，但不能改名、删除、上传。

## 三、第一步：配置自己的大模型 Key（重要）

### 3.1 为什么建议每个人用自己的 Key

系统调用的是公司 demoproduct 大模型平台（底层走 UIS 网关）。**一把 Key 大约只有 2 路并发**，所有人共用系统里的「公共 Key」时，人一多就会互相排队：

- 提问后一直显示「正在准备 / 已等待 xx 秒」；
- 偶尔提示「大模型调用太频繁（429）」或网关超时；
- 别人问长问题时，你也会被拖慢。

解决办法：**每个人申请自己的 Key**，各走各的通道，互不影响。

登录后看右上角：

| 徽标 | 含义 |
|---|---|
| 🟠 **👥 公共 Key** | 你正在用大家共用的 Key，高峰期可能排队 |
| 🟢 **🔑 我的 Key** | 你正在用自己的 Key，不受别人影响 |

### 3.2 申请个人 Key

1. 打开公司 demoproduct 大模型平台：

   ```
   http://demoproduct.examplecorp.com/ai_market/API
   ```

2. 按公司内部文档注册/申请 Key（**具体注册流程见公司里的文档**）。
3. 复制生成的 Key。部分页面只显示一次，建议先保存到安全的地方。
4. 如果找不到申请入口，找导师或管理员协助。

> **只支持公司 demoproduct 大模型平台签发的 Key。**
> OpenAI、DeepSeek 官网、通义等外部厂商的 Key 填进来无效——本系统只会用它访问公司内网网关。
> 系统「我的 Key」弹窗里也放了上面的申请入口。

### 3.3 在系统里填写并测试

点右上角「**👥 公共 Key**」（或「⚙ 更多 → 🔑 我的大模型 Key」）。

> **图：我的 Key**（截图已从公开仓库移除；本地启动后可在浏览器查看对应界面。）

1. 把申请到的 Key 粘贴到输入框；
2. 点「**先测试**」，确认提示「Key 可用」；
3. 点「**测试并保存**」；
4. 右上角徽标变成「**🔑 我的 Key**」就成功了。

补充说明：

- Key 只保存在服务器上、按用户隔离，**只影响你自己**，不会覆盖别人的 Key。
- 如果以后 Key 过期或被回收，点「我的 Key」重新填一把即可。
- 想改回公共 Key，点弹窗底部「改回使用公共 Key」。

### 3.4 Key 常见报错

| 提示 | 原因 | 处理 |
|---|---|---|
| Key 无效 / 401 | 填了外部厂商 Key，或 Key 已过期 | 换成 demoproduct 平台签发的 Key |
| 429 / 调用太频繁 | 公共 Key 并发被占满 | 申请并填写自己的 Key |
| 一直等待 / 超时 | 公共 Key 排队或网关慢 | 先点「⏹ 停止」，改用自己的 Key 再试 |

## 五、提问与看答案

### 5.1 选择知识库

在左侧单击「业务手册（O32/资管培训）」。选中后，输入框会提示「向「业务手册」提问」。

- 一个知识库 = 一个项目/主题的资料。**选错库，系统当然答不上来。**
- 别人分享给你的库会标注「只读」，能问不能改。

### 5.2 提问

> **图：提问与回答**（截图已从公开仓库移除；本地启动后可在浏览器查看对应界面。）

直接在输入框输入问题，回车或点「发送」。

提问建议：

- **问具体一点**：与其问「O32 怎么用」，不如问「Oracle 监听器怎么配置，怎么确认实例注册？」；
- **用文档里的原词**：文档写「日初」，就问「日初」，比问「早上开机」更容易命中；
- **一次可以问复合问题**：系统会自动拆成多个子查询并行检索；
- **把处境写进去**：例如「我是刚入职的新人，这个系统主要包含哪些模块？」。

### 5.3 看引用与原文

> **图：引用与原文**（截图已从公开仓库移除；本地启动后可在浏览器查看对应界面。）

- 回答上方有来源标识：📚 知识库 / 🌐 网络搜索 / 🧠 大模型知识。
- 点「📎 引用 N 个片段」展开，编号（■ 1、■ 2 …）与正文里的 `[1]`、`[2]` 一一对应。
- 点文件名可打开原文件预览，并定位到对应段落；预览保留标题、表格和插图。
- 引用里有缩略图时，点开看大图，按 `Esc` 或点空白关闭。

> 如果回答里出现「片段中未找到」「文档中没有明确说明」，说明知识库确实没有写这块，或者你的问法和文档用词差太远。先换个问法；还不行就问导师，或把资料补进知识库。

### 5.4 追问（上下文）

**上下文默认关闭**，每次提问独立理解。需要追问时：

1. 点输入框右侧的「💬 上下文：关」，变成「💬 上下文：开」；
2. 再问「那它的端口是多少？」这类省略问题，系统会结合上一轮理解。

- 开启后最多带最近 3 轮对话；
- 切换知识库会自动清空上下文；
- 关闭上下文也会清空已记录的上文。

### 5.5 换个回答、停止与反馈

- 觉得答偏了：点回答下方「↻ 换个回答」，原地重新生成；
- 等待太久：点「⏹ 停止」；
- 回答有用/没用：点 👍 / 👎。**差评会被管理员看到，用来补知识库**。

> 同一问题短时间内再问，可能显示「📚 知识库（缓存）」，这是正常的答案缓存；点「↻ 换个回答」会强制重新生成。

## 六、答辩演练（新人练习）

### 6.1 入口

点右上角「**🎓 答辩演练**」，会在新标签页打开，**不需要重新登录**。

### 6.2 上传 PPT、选择模式

> **图：答辩演练**（截图已从公开仓库移除；本地启动后可在浏览器查看对应界面。）

1. 上传你的答辩 PPT（支持 `.pptx` / `.ppt`）；
2. 选择模式：
   - **📖 练习模式**：每答完一题，立刻能看参考答案和依据，适合边学边练；
   - **🎯 答辩模式**：全程不给答案，全部答完才能统一看解析，模拟真实评委；
3. 选择题数：3 / 5 / 10 / 15 / 20；
4. 出题依据的知识库：默认「业务手册」，一般不用改；
5. 点「开始演练」。

### 6.3 答题与看参考答案

- AI 会结合你的 PPT、业务手册和 326 条历史答辩记录连续提问；
- 每道题下面可以看「参考答案和依据」，依据会标注「✓ 手册原文可核对」或「⚠ 未在手册中核对到」；
- 全部答完后才生成百分制报告：选 3 题时每题贡献约 33.3 分、总分 100；逐题得分、做得好的地方、还要补的地方、概念混淆点；
- 报告页可以点「📝 生成解析报告」，按需生成逐题解析（哪里对、哪里漏、概念有没有混淆），复用整场问答，不会拖慢单题的「看参考答案」。

> 两种模式**都能看答案**，区别只是时机：练习模式答完当前题就能看，答辩模式全部答完才能看。评分只在全部答完后进行。

> 题目生成后，系统会在后台预生成参考答案；点「看参考答案」通常直接复用，不需要重新等。如果正好还在生成，页面会显示「已等待 N 秒」。

> 如果提示「生成问题失败：大模型这次没有返回内容」，点页面上的「↻ 重试出题」即可；如果是答完题后生成下一题失败，回答会自动回到输入框，并出现「↻ 重试提交」按钮。多次出现可以在右上角填写自己的 Key。

## 七、补充内容与反馈

### 7.1 写内容（记录经验）

> **图：写内容**（截图已从公开仓库移除；本地启动后可在浏览器查看对应界面。）

点右上角「**✍️ 写内容**」：

- 直接写标题和正文，适合记录口头经验、临时结论、操作要点；
- **Ctrl+V 可以直接粘贴截图**，图片会一起入库；
- 保存后可以在下拉框里再次打开继续编辑。

> 如果你对某个知识库只有只读权限，「写内容」保存会被拒绝；可以写到自己新建的知识库里，或把内容发给管理员补充。

### 7.2 添加文件 / 拖拽

- 有写权限时，可以把文件或文件夹拖到页面中间，松手即加入当前知识库并自动建索引；
- 也可以点「添加文件」选择文件；
- 上传后索引在后台建立，**期间可以继续提问**。

### 7.3 索引刚更新时

添加内容后 1~2 分钟内提问，回答下方可能出现黄色提示：

> ⏳ 索引刚更新，正在后台加载（约 1–2 分钟），本条回答可能还没包含最新加入的文档。

这是正常现象，稍等再问即可，不是没加进去。

## 九、常见问题

**Q1：注册提示「只允许 @examplecorp.com 的邮箱注册」？**
用公司邮箱注册；个人邮箱（QQ、163、Gmail 等）不支持。公司邮箱也不行时找管理员。

**Q2：注册后两个入口都是灰的？**
新账号的「知识库」「模拟答辩」默认都未开通，找管理员在「用户管理」里勾选。开通知识库后默认拥有「业务手册（O32/资管培训）」只读权限；其他项目库需要额外分享。

**Q3：为什么我提问总是等很久，或者提示 429？**
你在用公共 Key，大家共用约 2 路并发。按第三章申请并填写自己的 Key。

**Q4：填了 Key 提示无效？**
本系统只认公司 demoproduct 大模型平台签发的 Key（申请入口 `http://demoproduct.examplecorp.com/ai_market/API`）；OpenAI、DeepSeek 官网、通义等外部 Key 无效。确认 Key 没复制错、没过期。

**Q5：回答「片段中未找到」怎么办？**
先确认选对了知识库，再换一个更贴近文档的说法；还不行就说明资料缺失，问导师或补充文档。

**Q6：追问时答非所问？**
上下文默认关闭。点「💬 上下文：关」变成「开」后再问。

**Q7：同一个问题第二次秒回，是假的吗？**
是答案缓存（24 小时内同库同问题）。点「↻ 换个回答」或开启演示模式可强制重新生成。

**Q8：回答里的 `[1]`、`[2]` 在哪看？**
点回答下方的「📎 引用」，编号一一对应；点文件名可打开原文。

**Q9：手机能用吗？**
可以，同一地址访问，自动切换移动布局。

## 十、给导师 / 管理员的附录

### 10.1 给新人分配知识库（只读、多选）

> **图：分配知识库权限**（截图已从公开仓库移除；本地启动后可在浏览器查看对应界面。）

两个入口等价：

- 左侧知识库右侧的「📤」按钮；
- 「⚙ 更多 → 👥 用户管理 → 📤 分配知识库权限」。

选择知识库，勾选一个或多个用户，点「保存分配」。被勾选的人只能提问和看引用，不能改名、删除、上传。

### 10.2 注册与账号

- 默认只允许 `@examplecorp.com` 邮箱注册；域名白名单在服务端配置。
- 配置 SMTP 后会启用邮箱验证码；未配置时按邮箱域名白名单直接注册。
- 管理员可在「👥 用户管理」里新建用户、重置密码、删除用户。
- **入口权限**：用户列表里每个账号有「知识库」「模拟答辩」两个勾选框，管理员可以单独开通/关闭；新账号默认都不开。开通「模拟答辩」会自动把该用户加入 O32 业务手册的只读共享。

### 10.3 运维命令

在项目根目录执行（Windows PowerShell，`rag` conda 环境）：

```powershell
$py = "$env:USERPROFILE\anaconda3\envs\rag\python.exe"

# 启动服务（或双击 start_rag.bat）
& $py app\server.py

# 健康检查
Invoke-WebRequest http://127.0.0.1:8000/api/health -UseBasicParsing

# 轻量备份（建议每天）
& $py backup.py --light

# 全量备份（建议每周）
& $py backup.py

# 检索质量评测（服务需在运行）
& $py -u eval\run_eval.py
```

> 重要数据目录：`app/data/`、`models/`、`index/`。不要手工删除；备份脚本只备份不可再生的数据，跳过可重建的索引。

本文档原先引用的界面截图未包含在公开仓库中（避免暴露真实环境）。本地启动后按上文各节操作即可看到对应界面：

| 场景 | 在哪里看 |
|---|---|
| 注册 / 登录 | 首页右上角「注册」/「登录」 |
| 我的大模型 Key | 右上角菜单 →「我的 Key」 |
| 主界面 / 提问与回答 | 选择知识库后进入问答页 |
| 引用与原文 | 回答下方的引用来源 |
| 答辩演练 | 入口页 →「模拟答辩」 |
| 写内容 | 回答页「笔记」 |
| 手机端 | 同一地址用手机浏览器打开 |
| 分配知识库权限 | 管理入口 → 知识库权限 |
