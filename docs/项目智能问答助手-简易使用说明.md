# 项目智能问答助手 · 简易使用说明

## 这是什么

把项目交付资料（用户手册、培训 PPT、Word/PDF/Excel、部署文档等）变成**可以直接提问、且能追溯原文**的知识库。

你问一句自然语言，系统先检索相关原文片段，再做重排，最后让大模型生成回答，并在正文里标出引用来源。点引用可以打开原文档、定位到对应位置。

适合两类独立场景：**知识库问答**（接手项目、查部署/升级/排障步骤、找环境信息）和 **模拟答辩**（新人培训后的考核、导师模拟提问、自测学习）。两者入口和权限分开，不是一条流水线。

## 解决什么问题

- **文档多、找不到**：几百份资料靠目录和关键词翻，同义说法搜不到；
- **回答不敢信**：普通聊天没有依据，答错也不知道错在哪；
- **交接靠问人**：同一个问题反复问老同事；
- **内网不能出网**：客户资料不能传到外部，模型和资料都要留在公司内网。

系统用“关键词检索 + 语义检索 + 重排 + 内网大模型”，支持多知识库、引用定位、用户权限隔离。

## 怎么用

1. 在公司内网用 Chrome/Edge 打开：`http://10.20.154.26:8000`（外网/VPN 需另开权限）。
2. 用公司账号登录。看不到知识库，找管理员开通并分享对应库。
3. 左侧选择一个知识库，例如「业务手册（O32/资管培训）」「O45常见业务用户手册」。
4. 输入问题，Enter 发送，Shift+Enter 换行。例如：
   - O32交易所指令怎么下单？
   - otrade 部署和升级要注意什么？
   - 测试环境和生产环境的数据库地址是什么？
5. 看回答。正文里的 `[1] [2]` 是引用，点开可以看原文和定位片段。
6. 答得不好：点「↻ 换个回答」重答；也可以点「🧠 大模型本地回答」，不查知识库、让模型凭自身知识答（可能会不准）。
7. 觉得有用/没用：点 👍/👎；点踩可以写一句原因，帮助改进。

## 上传自己的资料

- 在知识库管理里新建库，或直接上传文件/zip；
- 支持 Word / PDF / PPT / Excel / 文本 / CSV / JSON / DBF / 图片等；
- 支持 zip 批量导入；文件夹里已有的 zip 也会自动解压（最多 3 层），内部文档一起索引；
- SQL 脚本只按文件名索引，不读取脚本内容；
- 上传后等“索引完成”再提问，索引中提问可能搜不到；
- 多文件可并行上传。

## 模拟答辩（独立场景，有权限时）

- 两种入口：**上传培训/答辩 PPT**，或 **关键词直练**（不用 PPT，输入学习关键词，系统自动匹配知识库）；
- 出题难度可选：**基础（默认）** 按实施工程师带新人的角度问操作和皮毛业务；标准/挑战再逐步加深；
- **练习模式**：每题答完立刻看参考答案和得分点，适合新人自测学习；
- **答辩模式**：全程不给答案，全部答完统一看解析，适合导师考核；
- 答辩权限和知识库权限是分开的，没有入口或没有可选依据库，找管理员开通；
- 它不是知识库问答的前置或后续步骤，入口在右上角「🎓 答辩演练」。

## 人多时

- 系统最多**同时回答 10 个问题**；再多会**自动排队**，界面显示“前面还有几人 / 预计等待多少秒”，轮到后自动开始，不用重新问；
- 一个人同时最多 2 个问题，超出会提示；
- 公共大模型 Key 是大家共用的，高峰期会慢。急用可以申请自己的 **LightCode UIS Key**：
  - 打开「我的 Key」，按弹窗里的申请入口/申请文档申请；
  - 填入 Key，模型框填 `deepseek-flash`（或 `deepseek-v4-pro`），测试并保存；
  - 之后你的问题走自己的通道；管理员改全局模型不会覆盖你填的模型。

## 常见问题

| 提示 | 原因/处理 |
|---|---|
| 看不到知识库 / 403 | 找管理员开通知识库权限，并把对应库分享给你 |
| 一直排队 / 很慢 | 公共 Key 排队；可填个人 Key，或错开时间 |
| 429 | 你同时问了 2 个以上，或队列已满；等一会再试 |
| 422 / Key 无效 | 个人 Key 的模型不对；模型填 `deepseek-flash` 或 `deepseek-v4-pro` |
| 上传后搜不到 | 等索引完成；或确认当前选的是对应知识库 |
| 回答“没找到” | 该库可能没有这份内容；换库、补充资料，或问得更具体 |
| 交易所/开放式基金/期货混答 | 问题里尽量写清模块；系统会按模块过滤，避免拿错模块的片段 |

## 注意

- 仅在公司内网使用，资料不出内网；
- 不要上传与工作无关的私人文件；
- 回答是辅助，涉及账号、密码、生产操作请按公司流程复核。
