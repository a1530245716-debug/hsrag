# 常见故障排查

## 节点启动失败

检查端口是否被占用：`netstat -ano | findstr 8080`。
检查 JDK 版本是否满足 17+。
查看 `logs/startup.log` 中的第一条异常。

## 控制台无法登录

确认账号未被锁定，确认浏览器能访问控制台地址。
检查认证服务是否在线，检查系统时间是否与 NTP 同步。

## 行情延迟升高

检查网络丢包和消息队列堆积。
查看 market-service 的消费速率和 GC 日志。
必要时扩容行情服务实例。

## 数据库连接池耗尽

查看连接池活跃数和等待队列。
检查是否有慢 SQL 或未关闭的连接。
临时扩容连接池后，定位并修复泄漏点。
