# 示例交易平台概述

示例交易平台由交易网关、订单服务、行情服务、风控服务和运维控制台组成。
交易网关负责接入与协议转换，订单服务负责委托与成交，行情服务负责行情分发，
风控服务负责事前和事中校验，运维控制台负责配置与监控。

## 核心模块

- trade-gateway：对外接入，支持 FIX 和自定义二进制协议。
- order-service：委托、撤单、成交回报。
- market-service：行情订阅与快照。
- risk-service：额度、持仓、频率校验。
- ops-console：配置下发、节点管理、日志查询。

## 部署形态

测试环境为 3 节点，生产环境为 6 节点，数据库与消息队列独立部署。
